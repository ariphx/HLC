# HLC - Hop Limit Configurator

🛠️ Tool sederhana berbasis batch untuk mengatur dan me-reset Default Hop Limit (TTL) di Windows.

## 🚀 Fungsi Utama

🔓 **Bypass limit tethering Axis (unlimited)**  
Dengan mengganti default hop limit (TTL), kamu bisa **menghindari deteksi tethering oleh provider seperti Axis**, sehingga akses internet tetap unlimited tanpa terdeteksi hotspot tethering.

## 🧠 Fitur

- ✅ Set TTL (hop limit) ke 65 untuk Axis unlimited
- 🔄 Reset TTL ke nilai default (IPv4: 128, IPv6: 64)

## ⚙️ Cara Pakai

[![Download](https://img.shields.io/badge/Download-HLC.cmd-blue?style=for-the-badge)](https://github.com/ariphx/HLC/archive/refs/tags/v1.0.zip)

1. **Ekstrak file → HLC.cmd  → Klik kanan → Run as Administrator**
2. Pilih opsi:
   - `1` → Set hop limit ke 65 (untuk tethering Axis unlimited)
   - `2` → Reset ke default TTL Windows
   - `0` → Keluar

## 📌 Catatan

- Script ini **wajib dijalankan sebagai administrator** agar bisa mengubah pengaturan jaringan.
- Disarankan hanya untuk pengguna yang paham, gunakan dengan bijak 😎
